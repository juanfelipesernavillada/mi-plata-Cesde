## Acuerdos de trabajo

1. Confirmar entre ambos cambios importantes antes de integrar la entrega.
2. Usar mensajes de commit breves y descriptivos, por ejemplo: `feat: crear maqueta inicial de Mi Plata` o `docs: agregar historias de usuario`.
3. No subir claves, datos personales, tokens ni credenciales.
4. Mantener separado Mi Plata de cualquier otro proyecto académico.
5. Diferenciar la maqueta aprobada de la aplicación funcional y no describir una simulación local como un servicio bancario real.
6. Registrar los supuestos de cálculo cuando el enunciado no defina una fórmula completa.
7. Capturar evidencias reales de los módulos ejecutándose; no usar imágenes ilustrativas como prueba de funcionamiento.
