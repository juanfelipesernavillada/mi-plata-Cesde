# Evidencias de funcionamiento — Mi Plata

Este directorio está reservado para las capturas reales que acompañarán la entrega final. Las imágenes aún deben capturarse con la aplicación abierta y probada en el navegador; no se incluyen capturas de ejemplo como si fueran evidencia.

## Evidencias que solicita preparar el equipo

Guarda las capturas de pantalla con nombres descriptivos, por ejemplo:

1. `01-inicio.png` — landing y navegación responsive.
2. `02-registro.png` — formulario y validación de registro.
3. `03-login-intentos.png` — contador visible y mensaje de acceso fallido.
4. `04-bloqueo-tercer-intento.png` — bloqueo tras el tercer intento incorrecto.
5. `05-panel-cliente.png` — productos, saldos y resumen.
6. `06-consignacion-retiro.png` — operación válida y su mensaje.
7. `07-transferencia.png` — transferencia con movimiento en origen y destino.
8. `08-movimientos.png` — historial ordenado por fecha.
9. `09-tarjeta-cuotas.png` — compra con tasa y cuota mensual visibles.
10. `10-perfil-contrasena.png` — actualización de perfil o cambio de contraseña.
11. `11-panel-admin.png` — CRUD de usuarios y administración de productos de demostración.
12. `12-responsive.png` — interfaz en ventana estrecha o vista móvil.

## Cómo capturar evidencia auténtica

1. Ejecuta la app según las instrucciones de [`app/README.md`](../../app/README.md).
2. Repite cada escenario y captura la pantalla con la herramienta de Windows (`Win + Shift + S`).
3. Recorta datos y deja visibles la interfaz y el mensaje que demuestra el requisito. Utiliza únicamente datos ficticios.
4. Guarda las imágenes aquí y enlázalas desde esta guía o crea un documento PDF de evidencias para la entrega final.

Estas evidencias se completan después de probar la aplicación en el equipo del estudiante; las pruebas automatizadas por sí solas no sustituyen las capturas ni la demostración en vivo que pide el docente.
